# Website Mill Demo Lab

An interactive content and sales demonstration built for The Website Mill.

The fictional Oak & Stone Landscapes website demonstrates:

- weak versus conversion-led homepage positioning
- three live visual brand directions
- responsive mobile navigation
- project filtering
- before-and-after storytelling
- service-area checking
- a two-step quote journey
- accessibility and reduced-motion support

All names, testimonials and contact details are fictional. The project exists to create honest Website Mill demonstrations and social-media content without altering a client website.
